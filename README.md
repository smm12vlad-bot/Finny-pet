# Финни — путь к мечте

**Финни — путь к мечте** — функциональный прототип образовательной игры по финансовой грамотности для детей 7–11 лет. Ребёнок помогает виртуальному питомцу Финни: планирует игровой бюджет, выбирает между обязательными и необязательными расходами, формирует накопления, проходит обучающие задания и наблюдает, как финансовые решения отражаются на состоянии и развитии питомца.

Проект реализован на **JavaScript + Phaser 3.90.0**. Основной игровой цикл работает локально, без регистрации, рекламы, реальных платежей и постоянного подключения к Интернету.

Текущая версия предназначена для запуска и экспертной проверки в браузере на ПК или мобильном устройстве. Production-файлы формируются в каталоге `dist`.

## Основные возможности

В проекте реализованы:

- ввод игрового ника пользователя без телефона, e-mail и регистрации;
- виртуальный питомец **Финни** с фиксированным именем;
- настройка внешнего вида питомца;
- **9 визуально различимых комбинаций**: 3 аксессуара × 3 цвета аксессуара;
- аксессуары: **листик, бантик, звезда**;
- цвета аксессуаров: **зелёный, розовый, голубой**;
- **3 стадии развития** Финни: молодая, средняя и взрослая;
- отдельные изображения и эмоции для каждой стадии развития;
- эмоциональные состояния питомца: нейтральное, радостное, грустное и задумчивое;
- на главном экране эмоция Финни зависит от его текущего состояния;
- в тестах Финни отображает задумчивую эмоцию до ответа, радостную после правильного ответа и грустную после ошибки;
- показатели состояния питомца, включая сытость и настроение;
- внутриигровая валюта — **бамбунчинки** `🎋`;
- планирование бюджета по трём направлениям: обязательные расходы, необязательные расходы и накопления;
- контроль превышения бюджета и запрет отрицательного баланса в обычном режиме;
- покупки обязательного и необязательного типа с подтверждением и объяснением последствий;
- выбор финансовой цели, пополнение копилки и получение накопленной цели;
- история финансовых действий и результатов;
- сравнение плана бюджета с фактическими расходами;
- обязательный чек-лист игрового периода;
- последовательное развитие питомца по итогам финансовых решений;
- раздел для взрослого с арифметической защитой;
- настройки крупного текста, повышенного контраста и отключения анимаций;
- локальное сохранение прогресса после закрытия и повторного запуска приложения;
- удаление локального профиля;
- тестовый режим для экспертной проверки.

## Образовательный контент

В приложении предусмотрено **5 последовательных игровых периодов**:

1. **Бюджет без путаницы**.
2. **Накопления и цель**.
3. **Дом: потребности и бытовые расходы**.
4. **Свет, вода и коммунальный бюджет**.
5. **Семейный бюджет: покупки, счета и резерв**.

Для обучения используются отдельные JSON-файлы в каталоге `content`, поэтому образовательный контент отделён от интерфейсной логики и может расширяться без полной переработки приложения.

Сейчас в проекте:

- 5 учебных блоков;
- 15 тестов;
- по 3 уровня тестов на каждый блок: базовый, практический и сложный;
- по 5 вопросов в каждом тесте;
- всего **75 вопросов**;
- проходной результат — 4 правильных ответа из 5;
- объяснение результата после ответа;
- повторное прохождение теста;
- обновление наград за тесты каждые 12 часов в обычном режиме;
- 12 товаров и платежей;
- 5 финансовых целей;
- 5 игровых периодов;
- 3 стадии развития питомца.

## Тестовый режим для экспертов

Для быстрой проверки обязательного игрового сценария предусмотрен отдельный **тестовый режим для экспертов**.

Он запускается из раздела:

**Ещё → Для взрослого → решить арифметический пример → Тестовый режим для экспертов**.

При запуске режима:

- обычный локальный прогресс пользователя сохраняется отдельно;
- создаётся отдельный тестовый профиль **«Эксперт»**;
- все тесты становятся доступны сразу;
- отключается ожидание календарных сроков;
- бамбунчинки становятся безлимитными и отображаются как `∞ 🎋`;
- покупки не уменьшают доступный баланс;
- перевод средств в накопления не уменьшает доступный баланс;
- можно последовательно проверять бюджет, задания, покупки, накопления и переходы между периодами;
- тестовый профиль можно сбросить к исходному состоянию;
- доступна отдельная кнопка **«Выйти из тестового режима»**;
- после выхода восстанавливается обычный прогресс, сохранённый до запуска экспертного режима.

Тестовый режим предназначен только для демонстрации и не изменяет правила обычной игры.

## Короткий сценарий экспертной проверки

Рекомендуемый порядок проверки:

1. Запустить приложение и пройти вводное знакомство.
2. Создать локальный игровой профиль.
3. Выбрать внешний вид Финни: аксессуар и его цвет.
4. На главном экране проверить баланс, накопления, финансовую цель, состояние и текущий период.
5. Открыть раздел бюджета и распределить средства между обязательными расходами, желаниями и накоплениями.
6. Пройти учебный материал и тест, проверить правильный и ошибочный ответ.
7. Выполнить обязательную и необязательную покупку.
8. В обычном режиме проверить попытку покупки при недостатке средств.
9. Выбрать финансовую цель и пополнить накопления.
10. Завершить требования периода и перейти к следующему игровому периоду.
11. Проверить изменение состояния, эмоции или стадии развития Финни.
12. Обновить страницу и убедиться, что прогресс сохранился.
13. Перейти в раздел для взрослого.
14. Запустить тестовый режим эксперта и проверить открытие всех тестов и безлимитную валюту.
15. Выйти из тестового режима и убедиться, что обычный прогресс восстановлен.

## Быстрый запуск в Windows

Требуется **Node.js 20 или новее**.

1. Распакуйте проект в отдельную папку.
2. Запустите `start_windows.bat`.
3. Локальный сервер откроет приложение в браузере по адресу:

```text
http://127.0.0.1:4173
```

4. Не закрывайте окно сервера во время работы приложения.
5. Для остановки сервера нажмите `Ctrl+C`.

Устанавливать npm-зависимости не требуется: Phaser уже находится в каталоге `vendor`.

> Не рекомендуется открывать `index.html` двойным щелчком. Контент загружается из локальных JSON-файлов, поэтому проект следует запускать через локальный сервер.

## Запуск из PowerShell

```powershell
cd C:\путь\к\проекту
node --version
npm start
```

Если стандартный порт занят:

```powershell
$env:FINNY_PORT=4180
npm start
```

## Запуск на телефоне по Wi-Fi

1. Подключите ПК и телефон к одной локальной Wi-Fi сети.
2. Запустите `start_lan_windows.bat`.
3. При необходимости разрешите Node.js доступ к частной сети в брандмауэре Windows.
4. В консоли появится локальный адрес для телефона, например:

```text
http://192.168.1.45:4173
```

5. Откройте этот адрес в браузере телефона.

Если соединение отсутствует, проверьте VPN, гостевой режим Wi-Fi и настройки локальной сети.

## Данные и сохранение

Игровой прогресс хранится локально в браузере. Сервер, внешний аккаунт и передача персональных данных для основного сценария не требуются.

Сохраняются, в частности:

- игровой профиль;
- текущий период;
- баланс и накопления;
- бюджетный план;
- история покупок;
- выбранная и полученные финансовые цели;
- результаты тестов;
- состояние и развитие питомца;
- настройки интерфейса.

Удаление профиля выполняется через защищённый раздел для взрослого.

## Архитектурные принципы

Проект разделяет:

- пользовательский интерфейс;
- игровую экономику;
- состояние и локальное хранение;
- учебный контент;
- визуальную сцену питомца.

Учебные данные находятся в JSON-файлах и не зашиты непосредственно в разметку экранов. Новые задания и контент можно добавлять без полной переработки основной игровой логики.

## Ограничения текущей версии

- текущая версия является веб-прототипом;
- APK/AAB Android не входит в текущую браузерную сборку;
- перед финальной публикацией необходимо проверить приложение на физическом Android-устройстве;
- имя питомца в текущей версии фиксировано: **Финни**;
- основной игровой цикл рассчитан на локальную работу без сервера;
- тестовый режим предназначен для экспертов и не является частью обычной экономики пользователя.
