# Матрица соответствия требованиям

Статусы: **готово** — реализовано и покрыто проверкой; **проверка** — требуется ручной прогон; **APK-этап** — выполняется после приёмки веб-версии.

| Требование | Статус | Реализация / проверка |
|---|---|---|
| Короткое знакомство и три вида решений | готово | onboarding, шаг 1 чек-листа |
| Локальный профиль без регистрации и ПД | готово | профиль запрашивает только игровой ник и имя питомца |
| Настройка имени и внешности | готово | 3 окраса × 3 аксессуара |
| Главный экран со всеми ключевыми показателями | готово | `homeTemplate`, шаг 4 |
| Объяснённый источник дохода | готово | `periods.json`, история доходов, обратная связь |
| Бюджет: обязательное, желания, накопления | готово | `confirmBudget`, экран бюджета |
| Запрет превышения бюджета | готово | автоматические тесты |
| План/факт | готово | экран бюджета, итог периода, история |
| Две категории покупок | готово | 5 обязательных и 5 желаемых товаров |
| Подтверждение и влияние до покупки | готово | модальное окно проверки покупки |
| Нехватка средств и отсутствие отрицательного баланса | готово | `purchase`, автоматические тесты |
| История покупок | готово | экран прогресса |
| Не менее трёх целей | готово | 5 целей в `goals.json`, новая цель в каждом периоде |
| Пополнение накоплений | готово | экран цели и `deposit` |
| Практическое применение достигнутой цели | готово | стоимость списывается из копилки, цель попадает в коллекцию и используется раз за период |
| Отдельное подтверждение снятия и новый срок | готово | двухэтапное окно снятия |
| Не менее шести заданий по трём темам | готово | 3 блока, 6 тестов и 30 вопросов |
| Теория перед практикой | готово | отдельный экран теории, практика закрыта до базового теста |
| Задания не только с выбором ответа | готово | вопросы типа `amount` |
| Объяснение после каждого ответа | готово | `successExplanation` и `retryExplanation` |
| Уровни сложности и понятные награды | готово | easy/medium/hard/expert/master, монеты и XP растут вместе со сложностью |
| Постепенное усложнение обучения | готово | пять уровней сложности, последовательное открытие теории и практики |
| Запрет преждевременного перехода | готово | `getPeriodRequirements` и обязательный чек-лист на главном экране |
| Повторяемый цикл заданий | готово | награды обновляются через 24 часа, учебный прогресс и история сохраняются |
| Каждое финансовое действие меняет видимый результат | готово | баланс, накопления, показатели и обратная связь |
| Восстановление после ошибки | готово | повтор ответа, подсказки, отсутствие штрафа |
| Не менее трёх стадий питомца | готово | `getPetStage`, визуальные отличия Phaser |
| Рост за несколько периодов | готово | `growthPoints`, тест четырёх периодов |
| Объяснение состояния питомца | готово | `getPetExplanation` на главном экране |
| История периодов и текущая цель | готово | экран прогресса и главный экран |
| Короткий словарь | готово | экран помощи |
| Раздел взрослого с защитой | готово | арифметический пример |
| Прогресс без негативных ярлыков | готово | нейтральные и поддерживающие формулировки |
| Сброс и удаление данных | готово | раздел взрослого с подтверждением |
| Сохранение после перезапуска | готово | основное и резервное локальное сохранение, тест |
| Деморежим без ожидания | готово | тестовый профиль в разделе взрослого |
| Добавление контента без изменения ядра | готово | `content/*.json`, руководство по контенту |
| Не менее пяти периодов | готово | 5 записей в `periods.json` |
| Размер интерактивных элементов 48 dp | проверка | основные кнопки и строки имеют минимум 48 px; ручная проверка 360 px |
| Основной текст от 16 sp и увеличение | готово | базовый размер браузера 16 px, настройка крупного текста |
| Цвет не единственный индикатор | готово | текст, значки и числовые значения |
| Отключение анимации | готово | настройка в разделе взрослого и `prefers-reduced-motion` |
| Работа без Интернета | готово | локальные Phaser, данные и иконка; внешних запросов нет |
| Разделение логики, контента, хранения и UI | готово | модульная структура, `architecture.md` |
| Автоматическая проверка ключевой экономики | готово | 53+ теста Node Test Runner, включая полное прохождение пяти периодов |
| Android 8+, портретный режим | APK-этап | будет задано в Capacitor/AndroidManifest |
| Только необходимые Android-разрешения | APK-этап | планируется ноль дополнительных разрешений |
| Запуск ≤ 5 секунд и отклик ≤ 1 секунды | APK-этап | измерение на физическом устройстве |
| Уникальный package name, версия и build number | APK-этап | будут зафиксированы перед release-сборкой |
| Подписанный APK и необязательный AAB | APK-этап | после пользовательского тестирования веб-версии |
| Карточка RuStore, PNG 512, 3 скриншота | APK-этап | финальный комплект публикации |
| Физическое Android-тестирование | APK-этап | API 26, современный Android и устройство 3 ГБ+ |
