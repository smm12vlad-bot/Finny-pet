# Как изменять учебный контент

Контент отделён от экранов и правил игры.

## Теория и тесты

Файл `content/lessons.json` содержит три учебных блока. В каждом блоке есть вступление, три смысловых раздела, формула, пример и памятка.

Файл `content/tasks.json` содержит шесть тестов: по теоретическому и практическому тесту для каждого блока. Каждый тест содержит ровно пять вопросов двух типов:

- `choice` — выбор одного решения из вариантов;
- `amount` — самостоятельный ввод числового ответа.

Обязательные поля теста: `id`, `blockId`, `title`, `testType`, `difficulty`, `unlockPeriod`, `reward`, `xp`, `passScore`, `questions`.

Вопрос содержит `id`, `type`, `prompt`, `successExplanation` и `retryExplanation`. Для `choice` добавляется массив `options`, для `amount` — `correctAmount`.

Уровни сложности: `easy`, `medium`, `hard`, `expert`, `master`. Поле `unlockPeriod` определяет период открытия теста. Практический тест дополнительно требует сдачи теоретического теста своего блока. Проходной результат — 4 из 5.

Темы и идентификаторы блоков: `budget`, `savings`, `purchases`. Награды `reward` и `xp` должны возрастать от теории к практике.

## Товары

Файл `content/items.json`. Категория `essential` означает обязательную покупку, `optional` — желаемую. Поле `kind: "food"` добавляет единицу в запас еды.

## Цели и периоды

- `content/goals.json` — название, описание, стоимость, период открытия, подпись действия и числовые параметры эффекта цели;
- `content/periods.json` — пять последовательных доходов, учебные цели и обязательные пункты чек-листа.

Для цели обязательны `unlockPeriod`, `actionLabel`, `effectDescription` и объект `effect` с полями `satiety`, `mood`, `confidence`. После покупки действие доступно один раз за игровой период.

Пункты `objectives` периода поддерживают типы `plan`, `purchase`, `deposit`, `theory`, `tests`, `goal_owned` и `goal_used`. Переход открывается только тогда, когда выполнен каждый пункт.

После редактирования выполните `npm test`. Тест минимального объёма сообщит, если контента стало меньше требований ТЗ.
