# Архитектура проекта

## Выбранный подход

Приложение является локальной однопользовательской игрой. Серверная часть не используется. Node.js нужен только для локального запуска, тестов и подготовки папки `dist`; после упаковки в APK Node.js на телефоне не потребуется.

Phaser отвечает за комнату, питомца, аксессуары, стадии роста и анимацию. Элементы управления выполнены средствами HTML и CSS: это упрощает формы, прокрутку, крупный текст, фокус клавиатуры и экранное чтение.

## Компоненты

| Компонент | Назначение |
|---|---|
| `src/core/state.js` | схема и безопасная нормализация сохранения |
| `src/core/engine.js` | правила бюджета, покупок, накоплений, теории, тестов и периодов |
| `src/core/storage.js` | основное и резервное локальное сохранение |
| `src/core/content.js` | загрузка и минимальная проверка учебного контента |
| `src/game/pet-scene.js` | сцена Phaser, 9 вариантов питомца и 3 стадии |
| `src/ui/templates.js` | представления всех экранов |
| `src/main.js` | маршрутизация, обработка действий, формы и подтверждения |
| `content/*.json` | редактируемый учебный и игровой контент |

## Поток данных

1. При запуске `content.js` загружает пять локальных JSON-файлов.
2. `GameStorage` восстанавливает состояние или создаёт новый профиль.
3. Пользовательское действие передаётся в `GameEngine`.
4. Движок проверяет ограничения и возвращает понятный результат.
5. Успешное изменение сохраняется локально.
6. Интерфейс полностью перерисовывается из текущего состояния.
7. Сцена Phaser получает только данные внешности и состояния питомца.

Такое разделение позволяет тестировать финансовые правила без браузера и Phaser.

## Сохранение и восстановление

Текущая версия структуры состояния — `4`; ключ LocalStorage сохранён прежним для автоматического обновления старых профилей. Числа ограничиваются безопасными диапазонами, массивы и настройки получают значения по умолчанию. Перед перезаписью основного сохранения предыдущая версия переносится в резервный ключ.

## Офлайн-работа

- Phaser находится в `vendor`, а не загружается с CDN.
- Изображение иконки хранится локально.
- Питомец и комната рисуются кодом без внешних изображений.
- Контент хранится в локальных JSON-файлах.
- В приложении нет сетевых API, рекламы, аналитики и внешних ссылок для ребёнка.

## Подготовка Android

После приёмки веб-версии папка `dist` станет `webDir` проекта Capacitor. Android-этап добавит уникальный package name, портретный режим, адаптивную иконку, splash screen и release-подпись. Закрытый ключ останется вне исходного кода.
