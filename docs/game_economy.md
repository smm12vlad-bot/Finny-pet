# Правила игровой экономики

## Основные величины

- `balance` — доступные игровые монеты;
- `savings` — монеты в копилке;
- `plan` — план обязательных расходов, желаний и накоплений;
- `actual` — фактические покупки и взносы текущего периода;
- `xp` — опыт за тесты и итоги периода;
- `growthPoints` — успешные периоды, влияющие на стадию питомца.

## Ограничения

План допустим, если каждая категория больше нуля и выполняется условие:

```text
обязательные + желаемые + накопления ≤ доступный баланс
```

Покупка допустима только после подтверждения бюджета:

```text
цена товара ≤ доступный баланс
новый баланс = старый баланс − цена товара
```

При нехватке средств состояние не меняется, поэтому отрицательный баланс невозможен.

Пополнение копилки:

```text
новый баланс = баланс − сумма
новые накопления = накопления + сумма
```

Снятие из копилки выполняется только после отдельного предупреждения:

```text
новый баланс = баланс + сумма
новые накопления = накопления − сумма
примерный срок = округление вверх((стоимость цели − накопления) / регулярный взнос)
```

Когда стоимость цели собрана, игрок отдельно подтверждает её получение:

```text
если накопления ≥ стоимость цели:
новые накопления = накопления − стоимость цели
цель добавляется в коллекцию
```

Полученная цель даёт практическое действие, которое можно применить один раз за игровой период. Новый период снова открывает действие. Это связывает накопление с полезным результатом, но исключает бесконечное повторение бонуса.

## Итог периода

До расчёта итога проверяется обязательный чек-лист текущего периода. Если хотя бы один пункт не выполнен, состояние периода не меняется и следующий доход не начисляется. Требования построены только на действиях, которые можно доделать: чтение теории, сдача тестов, подтверждение плана, покупки, взнос, получение и использование цели.

Итоговая оценка ограничена диапазоном от 0 до 100:

- 10 баллов — базовое завершение периода;
- до 25 — обязательная покупка;
- до 20 — соблюдение плана желаемых покупок;
- до 25 — выполнение плана накоплений;
- до 20 — сданный тест текущего периода.

Ошибка не отнимает монеты и не ухудшает питомца. После ошибки показывается объяснение и остаётся возможность повторить действие.

## Рост питомца

Успешным считается период с результатом не ниже 60. Стадии:

1. 0–1 успешный период — «Любознательный малыш».
2. 2–3 успешных периода — «Уверенный исследователь».
3. 4–5 успешных периодов — «Мастер планирования».

Настроение, сытость и уверенность ограничены диапазоном 0–100. Переход между периодами немного уменьшает сытость, но приложение всегда объясняет причину и доступный следующий шаг.

## Учебные блоки и награды

Курс содержит три блока: бюджет, накопления и покупки. В каждом сначала открывается теория, затем теоретический тест и практика. Каждый тест содержит пять вопросов, для зачёта нужны четыре правильных ответа.

Шесть тестов распределены по пяти уровням сложности. Награды возрастают от 30 монет / 40 XP за первый тест до 100 монет / 140 XP за итоговую практику.

В каждом периоде открывается как минимум один новый тест и новая цель накопления. Сложность растёт по схеме: основы бюджета → расчёты → стратегия накоплений → сравнение покупок → итоговое решение.

Награда за конкретный тест выдаётся один раз в текущем 24-часовом цикле. После окончания таймера награды снова доступны, но прочитанная теория, зачёт тестов, история ответов и общий XP не удаляются.
