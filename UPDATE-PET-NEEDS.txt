УХОД ЗА ФИННИ — ОБНОВЛЕНИЕ ПОВЕРХ ВЕРСИИ С 12-ЧАСОВЫМ СБРОСОМ

Сохраните копию проекта. Остановите сервер Ctrl+C. Распакуйте архив
рядом с package.json с заменой файлов, запустите npm run dev.
Обновите страницу Ctrl+F5, на телефоне перезагрузите вкладку.
Не очищайте данные сайта и используйте прежний адрес: там хранится профиль.

Сытость: минус 1 пункт каждые 6 минут (100 -> 0 за 10 часов).
Настроение: минус 1 пункт каждые 10 минут (100 -> 0 за 16 ч 40 мин).
Это выбранный баланс Финни, а не подтверждённые таймеры Talking Tom.
Время закрытой вкладки учитывается при следующем запуске.
При установке обновления отсчёт начинается без потерь задним числом.
Показатели не опускаются ниже нуля. Обучение не блокируется.
Кормление, покупки и использование целей восстанавливают показатели
по прежним правилам. Старые эффекты завершения периода сохранены.

Эмоции на главном экране (для всех трёх стадий):
хотя бы один показатель <=30: расстроен;
иначе хотя бы один <=50: задумчивый;
оба >=70: радуется;
иначе: обычный.
В тестах эмоции по-прежнему зависят от вопроса и правильности ответа.

Изменены только engine.js, state.js, pet-assets.js, main.js и их dist-копии.
Добавлены тесты. Теория, задания, оформление, фон и изображения не заменены.
Проверка: npm run verify — 65 тестов и production-сборка прошли.
Визуальная проверка в браузере/на телефоне здесь не выполнялась.
Скорость можно настроить в src/core/engine.js:
SATIETY_DECAY_MS и MOOD_DECAY_MS, затем npm run build.
